# MailChat

A chat-dialog based IMAP/SMTP email client with local AI integration, PGP-compatible encryption, phishing recognition and a tagging system.

- **Email as chats:** WhatsApp-style bubbles, group chats, quick replies, voice messages and file attachments.
- **On-device AI:** summaries, spam/phishing detection, custom tags, reply suggestions and appointment detection — running locally (Gemma via Google LiteRT) or via your own OpenAI-compatible endpoint.
- **Rich text formatting:** bold, italic, underline, alignment, font size, font family, colors and lists in replies — sent as clean HTML, with an undo button.
- **Security:** OpenPGP (RFC 4880) encryption, key exchange via QR/NFC/email, encrypted backups.
- **Privacy:** no ads, no tracking, no analytics. Your data leaves your device only to the recipient.
